APT Repository

Installs via apt and updates automatically with your system.

1. Add the GPG key
curl -fsSL https://aaddrick.github.io/claude-desktop-debian/KEY.gpg | sudo gpg --dearmor -o /usr/share/keyrings/claude-desktop.gpg
2. Add the repository
echo "deb [signed-by=/usr/share/keyrings/claude-desktop.gpg arch=amd64,arm64] https://aaddrick.github.io/claude-desktop-debian stable main" | sudo tee /etc/apt/sources.list.d/claude-desktop.list
3. Install
sudo apt update && sudo apt install claude-desktop

Supported Architectures

amd64 arm64

Updates

Future updates install automatically with your regular system updates.

sudo apt update && sudo apt upgrade

DNF Repository

Installs via dnf and updates automatically with your system.

1. Add the repository
sudo curl -fsSL https://aaddrick.github.io/claude-desktop-debian/rpm/claude-desktop.repo -o /etc/yum.repos.d/claude-desktop.repo
2. Install
sudo dnf install claude-desktop

Supported Architectures

x86_64 aarch64

Updates

Future updates install automatically with your regular system updates.

sudo dnf upgrade claude-desktop

AUR Package

The claude-desktop-appimage package is updated automatically with each release. Use any AUR helper:

Using yay
yay -S claude-desktop-appimage
Using paru
paru -S claude-desktop-appimage

Nix Profile

Basic install
nix profile install github:aaddrick/claude-desktop-debian
With MCP server support (FHS environment)
nix profile install github:aaddrick/claude-desktop-debian#claude-desktop-fhs

NixOS Configuration

Add to your flake.nix:

{
  inputs.claude-desktop.url = "github:aaddrick/claude-desktop-debian";

  outputs = { nixpkgs, claude-desktop, ... }: {
    nixosConfigurations.myhost = nixpkgs.lib.nixosSystem {
      modules = [
        ({ pkgs, ... }: {
          nixpkgs.overlays = [ claude-desktop.overlays.default ];
          environment.systemPackages = [ pkgs.claude-desktop ];
        })
      ];
    };
  };
}
